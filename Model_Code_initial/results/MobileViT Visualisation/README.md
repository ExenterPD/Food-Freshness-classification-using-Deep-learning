# Visualizations

This directory contains all generated visualizations and charts for the KFU Food Freshness Classification system.

## 📊 Visualization Files

### **MobileViT-Focused Charts**
- `mobilevit_training_curves.png` - Training progress for all metrics (Loss, Accuracy, Precision, F1)
- `mobilevit_performance_summary.png` - Performance comparison across MobileViT runs
- `mobilevit_training_efficiency.png` - Training efficiency analysis (convergence, epochs)
- `mobilevit_configuration_analysis.png` - Configuration comparison table

### **Complete System Charts**
- `classifier_comparison.png` - Performance comparison across all models
- `confusion_matrices.png` - Confusion matrices for all models
- `hyperparameter_analysis.png` - Hyperparameter tuning results
- `metrics_summary.png` - Comprehensive metrics overview
- `training_progress.png` - Training progress visualization
- `summary_report.txt` - Text summary of results

## 📈 Chart Details

### **Training Curves**
- **Loss**: Training and validation loss over epochs
- **Accuracy**: Training and validation accuracy progression
- **Precision**: Precision metrics over training
- **F1-Score**: F1-score progression (key metric)

### **Performance Summary**
- **Bar charts** comparing all metrics across runs
- **Color-coded** for easy interpretation
- **Value labels** for precise readings

### **Training Efficiency**
- **Epochs to convergence** analysis
- **Convergence speed** comparison
- **F1 score progression** (best vs final)
- **Improvement tracking**

## 🚀 Usage

These visualizations are ready for:
- **Presentations** - High-resolution PNG files

- **Analysis** - Detailed performance insights
- **Documentation** - Visual evidence of results

All visualizations are automatically generated from training results in the `../runs/` directory using the scripts in `../analysis_scripts/`.
